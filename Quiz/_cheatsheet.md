---

### 1. Security Control

* **Categories:** Technical (Logical), Administrative (Managerial), and Physical.
* **Function Types:** Preventive, Detective, Corrective, Deterrent, Compensating, and Directive.

### 2. Social Engineering & Identity Theft

* **Phishing:** Fraudulent emails to steal sensitive information.
* **BEC (Business Email Compromise):** Targeted fraud impersonating executives.
* **Typosquatting:** Registering misspelled domains of popular sites.
* **Pharming:** Redirecting users to malicious websites via DNS poisoning.

### 3. Cryptography & Hashing

* **DES (Data Encryption Standard):** Legacy symmetric-key algorithm.
* **AES (Advanced Encryption Standard):** Modern symmetric-key standard.
* **RSA (Rivest-Shamir-Adleman):** Standard asymmetric encryption algorithm.
* **ECC (Elliptic Curve Cryptography):** Efficient asymmetric encryption using curves.
* **MD5 (Message Digest 5):** Legacy hashing algorithm (prone to collisions).
* **SHA (Secure Hash Algorithm):** Modern hashing standard for integrity.
* **DHE (Diffie-Hellman Ephemeral):** Key exchange providing Perfect Forward Secrecy.

### 4. Identity & Access Management

* **PAM (Privileged Access Management):** Securing and monitoring administrative accounts.
* **SAW (Security Alert Writing):** Systematic documentation of security incidents.
* **ZSP (Zero Standing Privileges):** Providing admin access only when needed (Just-in-Time).
* **SAML (Security Assertion Markup Language):** XML-based standard for Single Sign-On.
* **OAuth (Open Authorization):** Framework for token-based delegated access.

### 5. Network Authentication & Tunneling

* **802.1x:** IEEE standard for Port-Based Network Access Control.
* **EAP (Extensible Authentication Protocol):** Authentication framework for networks.
* **RADIUS (Remote Authentication Dial-In User Service):** Centralized AAA protocol.
* **IPSec (Internet Protocol Security):** Suite for securing IP communications.
* **AH (Authentication Header):** IPSec protocol for packet authentication/integrity.
* **ESP (Encapsulating Security Payload):** IPSec protocol for data encryption.

### 6. Modern Network Architecture

* **SD-WAN (Software-Defined Wide Area Network):** Virtualized service that connects enterprise networks.
* **SASE (Secure Access Service Edge):** Converged cloud-based network and security.
* **ZTA (Zero Trust Architecture):** Strategy based on "Never Trust, Always Verify."

### 7. Facilities & Continuity

* **COOP (Continuity of Operations Planning):** Restoring essential functions during a crisis.
* **BCP (Business Continuity Planning):** Broad strategy for maintaining business during a disaster.
* **UPS (Uninterruptible Power Supply):** Battery backup for immediate power protection.
* **Vestibule:** Physical "mantrap" or double-door entry system.

### 8. Threat Intelligence & Vulnerabilities

* **OSINT (Open Source Intelligence):** Data gathered from public, legal sources.
* **CVE (Common Vulnerabilities and Exposures):** Dictionary of publicly known flaws.
* **SCAP (Security Content Automation Protocol):** Standards for automated security checks.

### 9. Systems Management

* **Baseline:** The minimum security "gold standard" for a system.
* **Puppet:** An automated configuration management tool (Infrastructure as Code).

### 10. Mobile Deployment Models

* **BYOD (Bring Your Own Device):** Employees use personal devices for work.
* **CYOD (Choose Your Own Device):** Employees pick from an approved list.
* **COPE (Corporate-Owned, Personally Enabled):** Business-owned but personal use is allowed.
* **COBO (Corporate-Owned, Business Only):** Business-owned with no personal use.

### 11. Directory & Email Security

* **LDAP (Lightweight Directory Access Protocol):** Querying and managing directory services.
* **SASL (Simple Authentication and Security Layer):** Framework for authentication in protocols.
* **SPF (Sender Policy Framework):** Identifies authorized mail servers for a domain.
* **DKIM (DomainKeys Identified Mail):** Cryptographic signature to verify email origin.
* **DMARC (Domain-based Message Authentication, Reporting, and Conformance):** Policy for handling SPF/DKIM failures.
* **S/MIME (Secure/Multipurpose Internet Mail Extensions):** Encrypting and signing email content.

### 12. Network Visibility

* **Netflow:** Protocol for collecting IP traffic metadata.
* **Network Monitor:** Real-time software or hardware for packet analysis.

### 14. Data Roles

* **Data Owner:** Senior executive ultimately responsible for the data.
* **Data Controller:** Entity that decides the purpose of data processing.
* **Data Processor:** Entity that handles data on behalf of a controller.
* **Data Custodian:** Technical role responsible for day-to-day data maintenance.

### 15. Assessments

* **Regulatory Assessment:** Audit against legal requirements (e.g., HIPAA).
* **Compliance Assessment:** Audit against industry standards (e.g., PCI-DSS).
